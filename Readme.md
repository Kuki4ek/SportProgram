# Спортакус

## Основная информация

Это приложение для получения полезных наград за тренировки.

Архитектура: клиент-серверная (мобильный клиент и монолитный бэкенд)

Стек клиента: Kotlin + Jetpack Compose

Стек серверной части: .NET 10 (C# + ASP)
