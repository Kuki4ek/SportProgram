# Стабилизация темы SportakusAuth — версия 1.17

Главное изменение — все функции, возвращающие цвет интерфейса, теперь читают роли из `MaterialTheme.colorScheme`. Отдельный `LocalSportakusDarkMode` удалён, чтобы состояние темы не могло расходиться с фактической цветовой схемой.

| Элемент интерфейса | Цветовая роль |
|---|---|
| Основной текст, текст в полях | `onSurface` |
| Второстепенный текст | `onSurfaceVariant` |
| Фон полей ввода | `surfaceVariant` |
| Фон выбранных плиток и значений колёс | `primaryContainer` |
| Текст выбранных плиток | `onPrimaryContainer` |
| Текст на зелёных кнопках | `onPrimary` |

Светлая и тёмная палитры в `Theme.kt` сохранены. Переход между темами по-прежнему выполняется через `SportakusTheme`, а поля продолжают задавать текст и курсор явно.

Изменены `InkColors.kt`, `Theme.kt`, `AuthScreens.kt`, `OnboardingScreens.kt`. Версия повышена до `1.17-scheme-color-source` (`versionCode = 18`).

Проведена статическая проверка обновлённых вызовов и архива. Полную сборку Gradle/Android SDK и визуальную проверку на реальном устройстве подтвердить в этой среде не удалось; выполните **Build → Rebuild Project** в Android Studio и проверьте ввод, скроллы и выбранные варианты в обеих темах.
