# SportakusAuth V2.0.9-light

## Исправление цвета текста в светлой теме

- Закреплена отдельная светлая палитра текста и полей ввода, не зависящая от унаследованного `LocalContentColor` и текущей роли Material color scheme.
- Вводимое значение в полях авторизации всегда использует тёмный цвет `#171A14`.
- Текст подсказки использует контрастный приглушённый цвет `#555B50`.
- Ошибки валидации отображаются красным `#BA1A1A`, успешная подсказка длины пароля — приглушённым тёмным.
- Цвет курсора задаётся зелёным `#79B505`.
- Общие функции цветов `InkColors.kt` для текста, вторичного текста, полей, выбранных вариантов и кнопок больше не зависят от динамического `MaterialTheme.colorScheme`; V2 остаётся строго светлой.

Сохранены сетевые запросы, токены, навигация и остальные экраны.

Версия: `2.0.9-light`, versionCode `33`.
