# SportakusAuth V2.0.11-light

## Доработки тренировки, профиля, поиска и админских экранов

### 1. Пауза и продолжение тренировки
- Кнопка паузы в панели активной тренировки стала интерактивной.
- При паузе секундомер останавливается, кнопка меняется на «Продолжить».
- После продолжения секундомер продолжает отсчёт с сохранённого значения.
- Завершение или запуск новой тренировки сбрасывает состояние паузы.

### 2. Локальное полное имя и данные сервера только для чтения
- Поле «Полное имя» больше не заполняется логином и по умолчанию пустое.
- Изменённое полное имя сохраняется локально в SharedPreferences отдельно для каждой учётной записи.
- Полное имя не отправляется на backend.
- Почта, телефон, логин, дата рождения, рост, вес и пол показываются как значения только для чтения.
- Сохранение имени не вызывает PUT `/api/users/me` и не изменяет серверные атрибуты пользователя.

### 3. Управление упражнениями
- Нижний системный отступ учтён в списке упражнений.
- Добавлен запас прокрутки внизу списка, чтобы последнее упражнение не оказывалось под системной навигационной областью.
- Экран добавления/редактирования упражнения учитывает системную навигацию и открытую клавиатуру.
- Кнопки «Отмена» и «Создать/Сохранить» остаются закреплёнными внизу доступной области, а форма прокручивается отдельно.

### 4. Поиск
- Переключатели списка и сетки теперь видны сразу при открытии вкладки поиска, даже если пользователь ещё ничего не ввёл.
- При пустом запросе выбранный режим применяется и к общему каталогу тренировок.

Версия: `2.0.11-light`, versionCode `35`.
