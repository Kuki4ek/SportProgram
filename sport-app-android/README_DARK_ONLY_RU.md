# SportakusAuth — светлая и тёмная темы

Этот архив уже не является dark-only сборкой: он поддерживает переключение темы на главном экране выбора способа входа. Нажми на значок солнца/луны в левом верхнем углу экрана «Спортакус — Двигайся и зарабатывай». Тема применяется ко всем страницам и сохраняется между запусками.

Для запуска открой в Android Studio папку, в которой находится `settings.gradle.kts`, дождись Gradle Sync и выполни Run.
