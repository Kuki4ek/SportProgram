# SportakusAuth V2.0.10-light

## Исправление принудительного затемнения Android

Приложение использует только светлую тему. В Android 10/11 системный Force Dark может автоматически перекрашивать светлые приложения, если он разрешён темой окна. Для исключения таких преобразований добавлено `android:forceDarkAllowed=false` в `Theme.SportakusAuth`, а также программный opt-out для `window.decorView` на API 29+.

Цвета Compose остаются заданными светлой палитрой приложения. Подчёркивание вводимого текста может временно добавляться клавиатурой Android для composing region и само по себе не является ошибкой оформления.

Версия: `2.0.10-light`, versionCode `34`.
