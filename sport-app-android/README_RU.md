# Спортакус — Android-клиент

Учебное Android-приложение на Kotlin и Jetpack Compose с тёмной темой и экраном анкеты.

## Запуск

1. Распакуйте архив в отдельную папку.
2. В Android Studio выберите **File → Open** и откройте папку с `settings.gradle.kts`.
3. Дождитесь Gradle Sync.
4. Выполните **Build → Rebuild Project**, затем нажмите **Run ▶**.

## Тестовый API

Приложение поддерживает редактирование базового URL сервера через кнопку **«Адрес сервера»** на стартовом экране. Адрес сохраняется между запусками.

Подключены:

- регистрация: `POST /api/auth/register`;
- вход: `POST /api/auth/login`;
- получение текущего пользователя: `GET /api/users/me` с заголовком `Authorization: Bearer <jwt>`.

ПРИМЕЧАНИЕ: последняя спецификация, присланная разработчиком, повторяет `/api/auth/register` в заголовке раздела «Вход». В коде используется `/api/auth/login`, поскольку этот маршрут был указан в более раннем контракте. Перед демонстрацией подтвердите маршрут с backend-разработчиком.

После успешной регистрации или входа приложение сохраняет JWT в `TokenStore` и открывает тестовую страницу. Она делает `GET /api/users/me` и выводит `Привет, <login>` по полю `login` ответа сервера.

Подробная инструкция: `README_SERVER_API_RU.md`.

## Адрес сервера

- Android Emulator, сервер на том же компьютере: обычно `http://10.0.2.2:5000`.
- Физический телефон в той же сети: IP компьютера и порт API.
- Между разными сетями: публичный HTTPS URL или туннель; внутренние адреса `localhost`/`10.0.2.2` не работают.

## Ограничения тестовой версии

JWT хранится в `SharedPreferences` как временное учебное решение. Для production нужны HTTPS и защищённое хранилище. OAuth Google/Яндекс, восстановление пароля и refresh-токены пока не подключены. Полную сборку нужно проверить в Android Studio.
