# Обновление SportakusAuth 2.0.1-light

- Маска российского телефона: `+7 (999) 999-99-99`; этот формат отправляется на сервер.
- Загрузка профиля после регистрации и входа через `GET /api/users/me`.
- Реальные поля профиля и статистика из ответа API; неизвестные значения остаются пустыми/нулевыми.
- В редакторе профиля нет местоположения и пароля.
- Убраны фиктивные значения статистики и истории поиска.
- В каталоге — по одному примерному занятию на каждую из четырёх категорий.
- Панель активной тренировки появляется только после старта и показывает таймер.
- Нижние действия тренировки закреплены на экране.
- CTA-зелёный `#79B505`; базовый фирменный зелёный не менялся.

**Ограничение интеграции:** endpoint `PUT /api/users/me` для сохранения профиля и точные маршруты восстановления/refresh/logout нужно сверить с backend. Полная сборка APK должна быть выполнена в Android Studio после Gradle Sync.
