# Исправление SportakusAuth 2.0.2-light

## Исправлено

В `AuthApp.kt` состояние `notice` объявлено после callback `loadCurrentProfile`, который обращался к этой переменной. Kotlin не разрешает такое обращение к локальной переменной до её объявления, поэтому компиляция завершалась ошибкой `Unresolved reference: notice` на строке 155.

Объявление `notice` перенесено выше `loadCurrentProfile`, до создания callback. Само состояние и логика отображения сообщений не менялись. Это устраняет указанную ошибку компиляции без изменения поведения экранов.

Версия повышена до `2.0.2-light` (`versionCode = 26`).

## Проверка

Архив распакован, изменённый файл проверен, архив сформирован заново. Запустить Gradle-сборку в текущей среде не удалось: Gradle Wrapper пытается получить Gradle 8.0 с `services.gradle.org`, но сетевой DNS-доступ к этому адресу недоступен. Поэтому исправление именно ошибки `notice` подтверждено по исходному коду; полная компиляция Android-проекта здесь не подтверждена.
