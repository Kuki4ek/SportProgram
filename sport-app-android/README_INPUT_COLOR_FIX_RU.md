# Исправление цветов текста и полей — версия 1.17

В этой версии убран отдельный `CompositionLocal`, через который интерфейс определял, тёмная ли тема. Все семантические цвета теперь читаются из того же `MaterialTheme.colorScheme`, который формирует видимый фон интерфейса.

## Основные правила

- Текст в полях `BasicTextField` и обычные надписи используют `onSurface`.
- Подсказки, подписи и второстепенные элементы используют `onSurfaceVariant`, где требуется вторичный цвет.
- Фон полей ввода использует `surfaceVariant`.
- Выбранные варианты используют согласованную пару `primaryContainer` и `onPrimaryContainer`.
- Основные кнопки используют цвет текста `onPrimary`.

Поля в проекте реализованы через `BasicTextField`, а не `OutlinedTextField`, поэтому `OutlinedTextFieldDefaults.colors(...)` к ним не применяется. Для `BasicTextField` явно задаются `textStyle` и цвет курсора, а в компонентах с кастомным оформлением также применяется `CompositionLocalProvider`.

## Проверка в Android Studio

1. Откройте папку проекта, в которой находится `settings.gradle.kts`.
2. Выполните **Build → Rebuild Project**.
3. На стартовом экране переключите тему.
4. Проверьте ввод и удаление символов в полях логина, почты, телефона и пароля.
5. Прокрутите значения роста, веса и даты рождения; выберите и снимите выбор с вариантов анкеты.
6. Повторите шаги в светлой и тёмной темах.
