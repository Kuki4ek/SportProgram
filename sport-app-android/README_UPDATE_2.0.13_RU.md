# SportakusAuth V2.0.13-light

## Уточнение хранения полного имени профиля

- Поле «Полное имя» остаётся редактируемым и сохраняется локально в `SharedPreferences` отдельно для каждой учётной записи.
- По умолчанию полное имя пустое; логин, почта и другие серверные поля не копируются в это поле.
- Полное имя не отправляется в `PUT /api/users/me`: сохранение имени на backend пока не реализовано.
- При загрузке профиля серверные данные объединяются с локально сохранённым полным именем.
- При выходе из аккаунта локальное имя не удаляется, чтобы оно восстановилось при следующем входе в ту же учётную запись.
- Из интерфейса не выводится пояснение о способе хранения имени.

## Версия

`2.0.13-light`, `versionCode = 37`.
