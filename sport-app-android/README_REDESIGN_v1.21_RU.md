# Спортакус — обновление интерфейса 1.21

## Что изменено

### Колёса выбора роста, веса и даты рождения

- Колесо показывает ровно пять строк: 5 × 36 dp = 180 dp.
- Два пустых элемента в начале и конце списка позволяют поставить минимальное и максимальное значения точно по центру.
- Каждая колонка даты имеет собственное состояние прокрутки.
- Пользовательская прокрутка и программная синхронизация разделены: обновление месяца/года не публикует случайное значение в колонку дня.
- При выборе месяца или года день меняется только в случае, когда текущего дня нет в новом месяце (например, 31 января → 28 февраля; 29 февраля → 28 февраля в невисокосный год).
- Минимальный рост 100 см доступен для выбора.

### Анкета и переход на главную

- После успешной регистрации с подтверждением почты открывается анкета.
- После завершения анкеты пользователь попадает на главную страницу приложения.
- Факт заполнения анкеты и имя профиля хранятся отдельно для каждой учётной записи, а не одним общим флагом на устройстве.
- При повторном входе в уже заполненный профиль анкета не показывается повторно.
- Для новой учётной записи ответы анкеты сбрасываются к первоначальным значениям.

### Главная, каталог и профиль

- Добавлены экраны главной страницы, поиска/каталога, активности, карточки упражнения и профиля по обновлённому PDF-макету.
- До появления API каталога используются демонстрационные карточки тренировок.
- Главная страница, поиск и карточка упражнения работают с этим временным каталогом.
- Редактирование имени профиля сохраняется локально.

### Админ-панель упражнений

- Список упражнений с поиском и статусами «Опубликовано» / «Скрыто».
- Создание упражнения.
- Редактирование названия, описания, параметров, противопоказаний, рекомендаций и шагов инструкции.
- Публикация и скрытие упражнения.
- Удаление с подтверждением; в диалоге также доступно скрытие вместо удаления.
- Список и изменения упражнений сохраняются локально в SharedPreferences и не пропадают после перезапуска приложения.
- В debug-сборке админ-панель доступна для проверки макета. В release-сборке пункт показывается при наличии административной роли в JWT.

## Что пока является заглушкой

- Каталог упражнений и админские CRUD-операции пока не подключены к PostgreSQL/API. Локальное сохранение нужно только для демонстрации интерфейса и пользовательских действий.
- Загрузка и управление изображениями упражнения пока представлены визуальной заглушкой.
- Запуск и выполнение тренировки пока показывают информационное сообщение; отдельный модуль выполнения не подключён.
- Некоторые разделы профиля (избранное, интеграции и настройки) пока представлены макетными пунктами.
