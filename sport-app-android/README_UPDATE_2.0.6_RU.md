# SportakusAuth V2.0.6-light

## Изменения

1. На экране поиска удалён отдельный блок категорий и все переключатели категорий. Главный список показывает тренировки, а поиск сопоставляет запрос с названием, кратким и полным описанием упражнения.
2. Фильтры по времени, интенсивности и коинам, а также переключение между сеткой и списком сохранены.
3. В редакторе профиля поле пола заменено на выбор из двух вариантов: «Мужской» и «Женский».
4. При загрузке профиля распознаются значения «Мужчина» / «Мужской» / `male` и «Женщина» / «Женский» / `female`. При сохранении отправляются значения «Мужчина» и «Женщина», совпадающие с существующими значениями анкеты.

## Версия

- `versionCode`: 30
- `versionName`: `2.0.6-light`

Изменения относятся только к интерфейсу поиска и редактору профиля. Формат данных тренировок и статистика не менялись.
