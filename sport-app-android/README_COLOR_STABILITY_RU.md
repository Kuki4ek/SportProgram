# SportakusAuth — единый источник цветов темы

## Что исправлено в версии 1.17

Ранее цвета текста, фона поля и выбранного пункта вычислялись через отдельный `LocalSportakusDarkMode`. Это дублировало состояние `MaterialTheme` и могло приводить к рассогласованию, если отдельный composable не получал ожидаемое значение локального флага.

Теперь `MaterialTheme.colorScheme` — единственный источник семантических цветов:

- обычный текст и вводимый текст — `onSurface`;
- второстепенный текст и иконки — `onSurfaceVariant`;
- фон полей — `surfaceVariant`;
- фон выбранных вариантов и значения колёс прокрутки — `primaryContainer`;
- текст выбранного варианта — `onPrimaryContainer`;
- текст на основных зелёных кнопках — `onPrimary`.

В светлой схеме фон приложения остаётся `#F8FAF5`, фон полей — белым, основной текст — чёрным. В тёмной схеме поля остаются тёмными, текст — светлым. Для выбранных элементов заданы согласованные пары фона и текста в обеих темах.

`LocalSportakusDarkMode` и `sportakusIsDarkTheme()` больше не используются для расчёта цветов, и не требуется угадывать тему по яркости поверхности. Переключение темы по-прежнему выполняется через `SportakusTheme(darkTheme = ...)`.

## Изменённые файлы

- `app/src/main/java/com/sportakus/auth/ui/theme/InkColors.kt` — все функции цветов обращаются к семантическим ролям `MaterialTheme.colorScheme`.
- `app/src/main/java/com/sportakus/auth/ui/theme/Theme.kt` — убран второй источник состояния темы.
- `app/src/main/java/com/sportakus/auth/ui/AuthScreens.kt` — переключатель способа подтверждения использует `primaryContainer` / `onPrimaryContainer`.
- `app/src/main/java/com/sportakus/auth/ui/OnboardingScreens.kt` — то же исправление для анкеты; поля и колесо прокрутки берут цвета из общей схемы.
- `app/build.gradle.kts` — `versionCode = 18`, `versionName = 1.17-scheme-color-source`.

## Проверка

Статическая проверка исходников и целостности ZIP выполнена при подготовке архива. Полную Android-сборку и визуальный прогон на эмуляторе в этой среде подтвердить не удалось. После открытия проекта в Android Studio выполните **Build → Rebuild Project** и проверьте обе темы, ввод/удаление текста, фокус поля, прокрутку колёс и выбор/снятие выбора плиток.
