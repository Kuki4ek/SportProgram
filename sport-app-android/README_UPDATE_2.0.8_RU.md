# SportakusAuth V2.0.8-light — восстановление сессии и logout

## Сохранение входа

- После успешной регистрации/входа `TokenStore.saveTokens()` сохраняет JWT и refresh-токен в `SharedPreferences` приложения (`MODE_PRIVATE`). Эти значения переживают закрытие процесса и повторный запуск приложения; удаляются при очистке данных приложения или локальном выходе.
- При запуске после Splash приложение проверяет сохранённый refresh-токен и выполняет `POST /api/auth/refresh`.
- При успехе сохраняет новую пару `jwt` + `refreshToken`, так как backend ротирует refresh-токен.
- Затем запрашивает актуальный профиль через `GET /api/users/me` и открывает главный экран либо незавершённую анкету для активного аккаунта.
- При HTTP 401 от `/refresh` очищает локальную сессию и просит войти снова.
- При сетевой ошибке или временной ошибке сервера не удаляет refresh-токен: показывает приложение с локально сохранённым состоянием пользователя, если оно есть, и повторяет обновление при следующем защищённом запросе/запуске.

## Выход из профиля

- Кнопка выхода вызывает `POST /api/auth/logout` через `AuthApi.logout()`.
- JWT передаётся в `Authorization: Bearer ...`, refresh-токен — в JSON `{ "refreshToken": "..." }`.
- Если logout отвечает 401, клиент сначала выполняет refresh и повторяет logout с новым JWT и ротированным refresh-токеном.
- После запроса локальные токены и активная локальная сессия очищаются в любом случае, чтобы пользователь мог выйти даже без сети.
- При ошибке backend пользователь увидит сообщение, что локальный выход выполнен, но сервер не подтвердил завершение сессии.
