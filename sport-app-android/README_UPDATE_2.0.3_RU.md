# Обновление SportakusAuth 2.0.3-light — визуальное соответствие макету

Версия: `2.0.3-light` (`versionCode = 27`). Основа: архив `SportakusAuth_V2_2.0.2-light` и предоставленный PDF `Sportacus_update(2).pdf`.

## Что изменено

- Нижняя навигация переработана в плавающую закруглённую панель с отступом от краёв и низа экрана. Центральная кнопка-молния вынесена вверх относительно панели и открывает выбор тренировки из текущего каталога.
- Значки нижней навигации заменены на контурные: главная, поиск, активность и профиль. Подписи удалены, как в макете.
- Поиск получил поле с кнопкой возврата, динамическую историю недавних запросов и категории, формируемые из каталога упражнений.
- В выдаче поиска добавлены переключатели списка и сетки. Режим списка показывает белую карточку с зелёной рамкой, красной заглушкой вместо изображения, названием, реальным значением коинов, длительностью и значком запуска. Сетка показывает две карточки в ряд.
- Сортировка по времени, интенсивности и коинам применяется к фактическому списку результатов. Дополнительный фильтр позволяет отбирать категории, которые реально присутствуют в каталоге.
- Карточка тренировки переработана по макету: крупная зелёная шапка, метрики, переключатели разделов, блок награды, инструкции и фиксированная нижняя панель с избранным и кнопкой начала.
- Профиль и редактор профиля приведены ближе к визуальному стилю макета. Значения статистики по-прежнему поступают из `UserProfile`; персональные поля редактируются без подстановки выдуманных значений.
- Основной фон и базовый фирменный зелёный уточнены по макету. Яркий `#79B505` остаётся цветом основных действий.
- Демонстрационные карточки по-прежнему дают по одному примеру на категорию, но у них больше нет выдуманной длительности: неизвестные параметры показываются как «Время не указано», коины и прочая числовая статистика остаются нулевыми.
- Убраны заранее выбранные ответы анкеты (пол, дата рождения, рост, вес, интенсивность и цели). Новая анкета начинается с пустых ответов. До выбора пользователем профиль не получает фиктивные персональные данные.
- Ключ локального предпросмотра каталога изменён с `v2` на `v3`, чтобы старые тестовые записи с придуманными значениями не подмешивались в новый экран.

## Динамические значения

Нижняя панель не привязана к конкретному экранному состоянию. Быстрый старт формирует варианты из текущего списка упражнений. Число результатов, количество упражнений в категории, коины, время, избранное, тренировки и статистика отображаются из соответствующих моделей/ответов, а не из значений макета.

## Проверка

ZIP упакован и проверен на целостность. Выполнение полной Gradle-компиляции в среде подготовки недоступно: Gradle Wrapper требует загрузить Gradle 8.0 с `services.gradle.org`, DNS/сеть в этой среде недоступны. Поэтому APK не сформирован и успешная сборка Android Studio не заявляется.
