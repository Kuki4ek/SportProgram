# Обновление SportakusAuth V2.0.14.1-light — исправления профиля и партнёров

Основа проекта: V2.0.14-light. Основной дизайн не менялся; изменены только указанные элементы поведения и административного доступа.

## Профиль

- Удалено поле «Полное имя». Отображаемое имя берётся из серверного `nickname`; если никнейм пустой, используются логин или email.
- Никнейм остаётся серверным полем и сохраняется через `PUT /api/users/me` (`newNickname`).
- Ввод телефона переведён на хранение только цифр и отдельную визуальную маску. Форматирование больше не переписывает строку в состоянии поля при каждом нажатии, поэтому курсор не должен перескакивать. Перед отправкой значение преобразуется к формату `+7 (999) 999-99-99`.
- Аналогичная маска применяется в форме телефона партнёра.
- Смена пароля теперь открывается отдельной кнопкой «Сменить пароль». После нажатия появляется поле «Новый пароль», кнопки показать/скрыть пароль и отменить смену. Пароль отправляется как `newPassword` только если пользователь ввёл новое значение.
- После сохранения серверный профиль загружается повторно, как и в V2.0.14.

## Роль и партнёры

- Роль читается из role-claim (или `is_admin`) JWT access token. В профиле отображается `Администратор · ADMIN`, если найдена роль ADMIN; иначе показывается значение роли из токена или «Роль не указана».
- Административные элементы интерфейса показываются на основании access token, а не `BuildConfig.DEBUG`.
- Для администратора добавлена заметная карточка «Добавить партнёра» непосредственно в профиле.
- В списке партнёров вместо малозаметной иконки отображается текстовая кнопка «Добавить».
- Существующий `POST /api/partners` используется для создания партнёра; backend по-прежнему обязан проверять роль ADMIN и может вернуть 403. Декодирование JWT на клиенте используется только для отображения UI, не является проверкой безопасности.

## Версия и проверка

- `versionCode = 40`
- `versionName = 2.0.14.1-light`
- Проверка синтаксиса Kotlin не обнаружила ошибок парсинга.
- Полная Android/Compose-сборка в текущей среде не выполнена: Gradle Wrapper 8.0 не смог загрузить дистрибутив с `services.gradle.org` из-за недоступности DNS/сети. Перед выпуском APK требуется открыть проект в Android Studio и выполнить Gradle Sync и Rebuild Project.
