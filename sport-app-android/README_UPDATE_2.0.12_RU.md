# SportakusAuth V2.0.12-light

## Валидация логина и пароля

Клиентская проверка регистрации приведена в соответствие с обновлёнными правилами backend от 05.11.

- Логин обязателен, не длиннее 50 символов, начинается с латинской буквы или `_`, далее допускаются только `A-Z`, `a-z`, `0-9`, `_`.
- Пароль обязателен, не короче 8 символов, содержит заглавную и строчную латинские буквы, цифру и специальный символ. Разрешены только латинские буквы, цифры и `!\"#$%&'()*+,-./:;<=>?@[]^{|}~`.
- Те же требования к паролю применяются при восстановлении пароля. При обычном входе проверяется непустое значение, чтобы не блокировать существующие учётные записи из-за изменения политики после регистрации.
- В поле регистрации подпись уточнена с «Твоё имя» на «Логин».

## Полное имя профиля — уточнение в V2.0.13

В первоначальном варианте V2.0.12 предполагалось сохранение через `PUT /api/users/me`. Позже выяснилось, что сохранение полного имени на backend ещё не реализовано. Поэтому начиная с V2.0.13 имя сохраняется локально отдельно для каждой учётной записи и не отправляется на сервер. Серверные поля профиля остаются недоступными для редактирования.
